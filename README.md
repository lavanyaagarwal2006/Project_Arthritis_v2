# Project Arthritis v2: erosion detection on hand radiographs

> **Research use only. Not a medical device. Not for diagnosis.**

This project trains deep-learning models that flag bone erosions on hand radiographs, the
radiographic hallmark of erosive rheumatoid arthritis. The goal is a clinician-facing aid
for spotting early erosions. It is not a standalone RA diagnosis.

This repo supersedes [Project_Arthritis_v1](https://github.com/lavanyaagarwal2006/Project_Arthritis_v1).
v1 was trained on the Roboflow RF100 x-ray-rheumatology set.

## Quickstart

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 1. Get data (gated: accept the terms on Hugging Face first, then log in, see docs/data.md)
bash scripts/download_data.sh            # -> data/RAM-H1200-v1/

# 2. Inspect the layout and write the manifest + splits (no GPU needed)
make inspect
make manifest splits

# 3. Smoke test on synthetic data (CPU, ~2 min). Run this before any real training.
make smoke

# 4. Train the model ladder with 5-fold patient-grouped CV, then evaluate
make train EXP=densenet121
make evaluate
```

## Layout

```
configs/      base.yaml + exp/<name>.yaml (one file per experiment)
docs/         analysis_plan.md, data.md, model_card.md, v1_postmortem.md
scripts/      download, inspect, synthetic data
splits/       committed patient->fold assignments (no images, ever)
src/arthritis manifest, splits, data, models, train, metrics, evaluate
results/      metrics.json + figures per run (committed); checkpoints are not committed
tests/        unit tests for metrics and splits
```
